Clockwork/coloring correspondence

Colors follow one fixed clock: A = phase 0, B = phase 1/N, C = phase 2/N, and so on. CN = (ABC…) is one forward +1/N-period tick, so a row with Time +k/N has Color CNk. Every action is a forward time skip; none reverses time. Raised numbers in the signature give colour-permutation orders, not time shifts.

Crystallographic generator symbols

Viewed along the clock axis, these are crystallographic projection symbols for the height-lifted generators, and they appear only on the static 2D diagram. A filled lens, triangle, diamond, or hexagon marks a 2-, 3-, 4-, or 6-fold axis; arms distinguish a screw axis nm. For a forward skip τ, m = nτ for a positive 1/n-turn and m = n(1−τ) for the oppositely oriented turn. Mirrored arms record spatial turn sense—not backward time.

For planes normal to the picture, a solid line is a mirror, a dashed line is an axial glide in the picture, a dotted line is a glide along the perpendicular clock axis, and a dash–dot line is a diagonal n-glide. An arrowed dash–dot line is the quarter-diagonal d-glide. The nearby α, β, γ, … or P, Q, … label matches the Generator row; its Color and Time columns state the same clock action explicitly.

Notation: International Tables for Crystallography projection symbols · UCL P 3 1 c example.

Notation

The displayed names use Chaim Goodman–Strauss’s coloured-orbifold notation. Across all 68 forward groups it gives 64 cyclic plane-colouring classes. Four types leave the two orientations of the polar fibre unresolved: 4424/◦, 3333/◦, 6326/◦, and 6323/2222.
